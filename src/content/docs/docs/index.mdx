Ikenga is an **open-source, local-first desktop workspace for coding agents**. It gives Claude Code and other agent engines a home on your own machine: your projects, your agent companion, and the apps and extensions you install, in one window.

The workspace has three parts. A **Project** is the folder you work in. **Chi** is your agent companion, where you hand work to an engine and approve what it asks to do. **Ngwa** is the store for apps and extensions. The [glossary](/docs/reference/glossary/) defines every term.

Ikenga is built on Tauri 2 and licensed Apache-2.0. The source is at [github.com/ikenga-hq/ikenga](https://github.com/ikenga-hq/ikenga).
