This section is for people who run an Ikenga server: on their own, to reach their workspace from another device, or for a team as a multi-user server. The step-by-step guides are still being written. Until they land, this page says what exists today and what it does not do yet.

## What exists today

Both server modes are in beta. Neither is part of the desktop download: you build and deploy the server yourself.
